０２．業務システムのクラウド移行及びインフラ統合プロジェクト

概要

大手素材メーカーの老朽化したオンプレミスシステムをAzure上に段階的に移行するプロジェクト(EOSL対応)である。 3事業部に分散していたシステムのインフラを1つの環境に統合することで運用費の削減と同時に、可用性・移行性・保守性を高める設計を実施した。 私はプロジェクトリーダーとして、非機能要件の定義や技術要素の選定を実施し、テストや非互換の調査、移行計画等一連ののフェーズを管理を担当した。 本プロジェクトは現在所属している会社の年に1度実施されるアワードにてチャレンジング部門を受賞した。

使用技術

  • Microsoft Azure(VM,SQL Database)
  • Azure Monitor
  • Azure Migrate
  • DB（Oracle,EDB）
  • EDB
  • Java

ポイント

  • 各事業部で異なる業務ロジックを維持しつつ、インフラの統合を実現
  • SLA・RTO・RPO要件に対応した冗長化構成と監視設計
  • 初めてのプロジェクトリーダーの経験

振り返り

クラウド移行に際しては、現行業務への影響を最小限に抑える移行計画が重要であった。 また、非機能要件のヒアリングと可視化が、品質・コスト・パフォーマンスのバランスを取る鍵となった。 将来的な拡張も見据えた設計により、全社DXの基盤づくりに貢献できた。 本プロジェクトも大規模案件でありながら、若手ながらプロジェクトリーダーとしてアサインして頂いた。 ベテラン社員のフォローもありながらも計20名近くの体制となるプロジェクトを成功させたのは大きな自信に繋がった。

０３．プライシングシステムの開発

概要

大手素材メーカーである営業部門の見積業務を効率化・標準化するためのプライシングシステムを構築。 社内データを活用した価格推定モデルと、ワークフロー承認機能を備えたローコードアプリを実装。 私はアプリケーションの部署所属でありながらも、クラウド（PaaS）の更なる技術習得を目的としてインフラチームのリーダーを担当した。 その他、プロジェクトとしての要件定義への参加、ローコードアプリ技術検証及び開発をリードした。

使用技術

  • Microsoft Azure PaaS（SQL Database,Azure App Service等）
  • Power Platform(Power Apps)
  • Python
  • Java

ポイント

  • バラつきの大きい価格設定の標準化に貢献
  • 既存システムや市場データから価格推定モデルを用いて営業の属人生を削減
  • 部内の知見が少ない技術（ローコード,PaaS）の利用
  • インフラチームリーダーとしての経験

振り返り

現場の業務フローを理解した上で、技術的に実現可能なアプローチを複数提案し、関係者と協議を重ねながら最適解を導いた。 機械学習と業務システムの連携には課題もあったが、PoCを通じて精度と実用性のバランスを取り、実運用に耐える形に仕上げることができた。 また、業務と並行してMicrosoft Azureの知識習得を目指しAzure Associate資格を取得することが出来たことがプロジェクト推進に役立った。 新規技術の調査を含めて第一人者としてアサインしたもらったことで技術者としての更なるスキルアップができた。
